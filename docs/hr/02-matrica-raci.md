# Документ 2. Матрица разделения обязанностей (RACI)

**R** — исполнитель; **A** — ответственный за результат (утверждает); **C** — согласование / консультация;
**I** — информируется. В каждой строке ровно одна **A**.

**Роли:** ПМ — продакт-менеджер; АПМ — ассистент продакт-менеджера; РГ — руководитель группы;
ГД — генеральный директор; КО — конструкторский отдел; ОТК/ПР — ОТК и производство;
ПРД — отдел продаж; МП — менеджер маркетплейсов.

## 2. Полномочия помощника

| Помощник **может** самостоятельно | Помощник **не может** без согласования ПМ |
|---|---|
| Ставить задачи по решениям из утверждённого МОМ и напоминать о сроках | Утверждать или менять сроки от имени ПМ |
| Отвечать на типовые вопросы по базе применяемости, FAQ, графику новинок | Подтверждать применяемость, отсутствующую в базе |
| Запрашивать у поставщиков цены, сроки, уточнения по утверждённому ТЗ | Отправлять ТЗ, принимать условия, согласовывать объёмы, цены, сроки поставки |
| Проводить первичную проверку КД по чек-листу и возвращать комплект на доработку по формальным замечаниям | Согласовывать КД, давать технические заключения по конструкции |
| Выполнять расчёты по утверждённым шаблонам | Передавать расчёты и цены клиентам |
| Регистрировать рекламации, запрашивать данные, организовывать разбор | Признавать или отклонять рекламацию, обещать компенсацию |
| Запрашивать данные у подразделений в рамках поручений ПМ | Принимать бюджетные обязательства |

## 3. Матрица эскалации

| Ситуация | Куда | Срок |
|---|---|---|
| Вопрос продаж вне базы применяемости | ПМ | В течение дня |
| Признаки дефекта изделия, повторяющаяся рекламация | ПМ + ОТК | Немедленно |
| Срыв срока подразделением по поручению МОМ | Ответственному → ПМ при повторном срыве | В день срыва |
| Поставщик меняет цену, срок или условия | ПМ | В день получения |
| Замечание по конструкции при проверке КД | ПМ | В заключении проверки |
| Репутационный риск (жалоба крупного клиента, публичный негатив) | ПМ → РГ | Немедленно |
