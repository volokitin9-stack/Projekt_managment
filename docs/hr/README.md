## Резюме аудита

**Должность:** продакт-менеджер (подчинение — руководитель группы). Прямых подчинённых нет.
Продукт — защиты картера для автомобилей (узкая применяемость, постоянный поток новинок).
Ответственность — бизнес-процессы продукта, себестоимость и доходность.

**Причины потребности в помощнике (со слов):** перегрузка по часам, срыв сроков (как собственных,
так и подразделений), запуск новой товарной группы, рост проектов и объёмов продаж, большой поток
вопросов от продаж.

### Баланс времени

| Показатель | Ч/мес | Источник |
|---|---:|---|
| Фактически отработано (9:30–20:00 × 5 дн.) | **227** | Факт |
| Норма (40 ч/нед.) | 168 | Норматив |
| Потребность по всем функциям | **≈ 320** | Расчёт, см. документ 1 |
| Дефицит (задачи, которые не выполняются или выполняются с опозданием) | **≈ 93** | Расчёт |
| Доля рутины в текущем времени | 60 % (≈ 136 ч) | Оценка пользователя |

**Ключевые причины перегрузки**

1. **Поток обращений (≈ 77 ч/мес):** ~30 звонков + ~100 писем + мессенджеры в день. Звонок каждые
   ~20 минут — фрагментация дня, невозможность концентрированной работы.
2. **Совещания (≈ 63 ч/мес),** чаще в роли организатора — плюс подготовка МОМ и контроль поручений.
3. **Новая ТГ (≈ 63 ч/мес по плану)** — фактически вытесняется рутиной. Именно здесь возникает
   срыв сроков.
4. **Внедрение Битрикс24 (≈ 22 ч/мес),** где пользователь — руководитель проекта, — новая нагрузка.

### Варианты должности помощника

| Критерий | 1. Административный помощник | 2. Технический ассистент / координатор проектов | 3. Помощник с аналитическими и проектными функциями |
|---|---|---|---|
| Протоколы, контроль сроков | ✔ | ✔ | ✔ |
| Первая линия продаж по применяемости | ✘ нужна техническая база | ✔ | ✔ |
| Переписка с поставщиками на EN (CN — плюс) | частично | ✔ | ✔ |
| Первичная проверка КД по чек-листу | ✘ | ✔ | частично |
| Расчёты себестоимости по шаблону, сводки МП, BI | ✘ | частично | ✔ |
| Закрываемый объём передаваемых функций | ≈ 25 % | ≈ 75 % | ≈ 70 % |
| Риск | Не снимает основную нагрузку | Нужен рост аналитических навыков | Слабее в КД и применяемости |

**Решение:** вариант 2 с аналитическим компонентом — **«Ассистент продакт-менеджера (технический
координатор продукта)»**. Основная нагрузка лежит в технико-коммуникационной зоне (применяемость, КД,
поставщики, сроки подразделений), которую административный профиль не закрывает. Аналитические
функции (OEM-расчёты, сводки МП, мониторинг цен) выполняются по шаблонам и осваиваются за 60 дней.

### Экономический и организационный эффект (установившийся режим, с 4-го месяца)

| Показатель | Значение |
|---|---:|
| Потребность в функциях продакт-менеджера | ≈ 320 ч/мес |
| Передаётся помощнику | ≈ 122 ч/мес |
| Снимается автоматизацией, оптимизацией совещаний и передачей подразделениям | ≈ 36 ч/мес |
| **Остаётся за продакт-менеджером** | **≈ 162 ч/мес** (в пределах нормы 168) |
| Загрузка помощника | ≈ 157 ч/мес + разовый проект базы применяемости ≈ 80 ч |
| Доля управленческой и продуктовой работы ПМ | 40 % → **≈ 59 %** |
| Время на новую ТГ | фактически < 63 ч (вытесняется) → **45 ч гарантированно** |
| **Формат занятости** | **Полная занятость** |

Высвобождение нарастает поэтапно: ~30–40 ч в 1-й месяц, ~70–80 ч во 2-й, ~110–120 ч в 3-й.

**Допущения:** средняя длительность звонка 3 мин, письма — 1 мин, мессенджеры — 0,5 ч/день;
трудозатраты на проверку КД, Китай, ценообразование, бюджет и обучение продаж — оценочные;
производительность помощника в установившемся режиме ≈ 1,2× от времени ПМ на ту же операцию.

### Условия эффекта (без них часть высвобождения не будет достигнута)

1. Создать базу применяемости «марка / модель / кузов / двигатель / годы → артикул» с доступом для продаж.
2. Ввести график новинок со статусами в Битрикс24, доступный продажам.
3. Утвердить матрицу эскалации (документ 2), чтобы продажи шли сначала к помощнику.
4. Провести ревизию совещаний, где ПМ не организатор: участие лично / через помощника / по протоколу.
5. Разработать чек-лист первичной проверки КД и шаблоны писем поставщикам до выхода помощника.
