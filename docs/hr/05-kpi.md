# Документ 5. KPI ассистента продакт-менеджера

**Период оценки:** месяц. **Источник данных:** Битрикс24 (задачи, журнал обращений, реестры), почта, отчёты.
Если по показателю нет автоматического учёта, его фиксирует ПМ в ежемесячной оценке.

## 1. Показатели

| № | Группа | Показатель | Формула / метод | Цель (с 4-го месяца) | Вес |
|---|---|---|---|---|---:|
| 1 | Своевременность | Рассылка МОМ в срок | Доля МОМ, разосланных ≤ 24 ч после совещания | 100 % | 10 % |
| 2 | Своевременность | Контроль поручений | Доля просрочек по поручениям МОМ, о которых ПМ узнал из еженедельного отчёта, а не постфактум | ≥ 95 % | 15 % |
| 3 | Самостоятельность | Закрытие обращений продаж без эскалации | Закрыто АПМ / всего обращений в журнале | ≥ 65 % | 20 % |
| 4 | Своевременность | Срок ответа на типовое обращение продаж | Доля ответов ≤ 4 рабочих часов | ≥ 90 % | 10 % |
| 5 | Качество | Ошибки в ответах по применяемости | Число подтверждённых ошибочных ответов | 0 | 10 % |
| 6 | Своевременность | Запросы поставщикам | Доля сводок КП, подготовленных ≤ 3 рабочих дней с момента получения ответов | ≥ 90 % | 10 % |
| 7 | Качество | Первичная проверка КД | Доля формальных замечаний, выявленных АПМ, от всех формальных замечаний (включая найденные ПМ позже) | ≥ 85 % | 10 % |
| 8 | Своевременность | Расчёты OEM | Доля расчётов по шаблону, переданных ПМ ≤ 1 рабочего дня | ≥ 90 % | 5 % |
| 9 | Качество | Возвраты на доработку | Доля результатов, принятых ПМ без доработки | ≥ 85 % | 5 % |
| 10 | Дисциплина полномочий | Превышение полномочий | Случаи принятия обязательств без согласования | 0 | 5 % |
| | | | | | **100 %** |

**Корректирующее правило.** Если по показателю 5 или 10 есть хотя бы один случай с последствиями для клиента или поставщика, премиальная часть за месяц уменьшается на 50 %.

## 2. Целевые значения на испытательный срок

| Показатель | 30 дней | 60 дней | 90 дней |
|---|---|---|---|
| 1. МОМ в срок | 90 % | 100 % | 100 % |
| 2. Контроль поручений | 70 % | 85 % | 95 % |
| 3. Обращения без эскалации | 25 % | 45 % | 60 % |
| 4. Ответ ≤ 4 ч | 70 % | 85 % | 90 % |
| 6. Сводки КП в срок | — (в копии ПМ) | 80 % | 90 % |
| 7. Первичная проверка КД | — (обучение) | 70 % | 85 % |
| 9. Принято без доработки | 60 % | 75 % | 85 % |

## 3. Проектные показатели (разовые)

| Результат | Срок | Критерий приёмки |
|---|---|---|
| База применяемости — ходовой ассортимент | День 75 | Покрыто ≥ 80 % ходовых артикулов, доступ у продаж |
| FAQ для продаж (установка, типовые вопросы) | День 60 | ≥ 30 вопросов, согласовано ПМ |
| График новинок в Битрикс24 | День 45 | Обновляется еженедельно, доступен продажам |
| Чек-лист и реестр КД | День 45 | Применяется ко всем новым комплектам |

## 4. Индикатор эффекта для ПМ (не KPI помощника)

| Индикатор | База | Цель к 90-му дню |
|---|---|---|
| Фактическое рабочее время ПМ | ≈ 227 ч/мес | ≤ 185 ч/мес; ≤ 170 ч/мес к 6-му месяцу |
| Обращения продаж к ПМ напрямую | ≈ 30 звонков/день | ≤ 10 в день |
| Время ПМ на новую ТГ | вытесняется | ≥ 45 ч/мес |
| Просрочки по спецификации новой ТГ | есть | нет |

## 5. Порядок оценки

1. АПМ до 3-го числа готовит самоотчёт по показателям из Битрикс24.
2. ПМ проверяет, выставляет оценку и проводит встречу обратной связи (30 мин).
3. Итог передаётся в HR для расчёта переменной части. Пример схемы: показатель выполнен на 100 % и выше — 100 % веса; на 80–99 % — пропорционально; ниже 80 % — 0.
