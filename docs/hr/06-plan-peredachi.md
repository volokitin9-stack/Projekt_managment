# Документ 6. План передачи функционала (30 / 60 / 90 дней)

**Уровни самостоятельности:**
- **У1** — «делаю, ПМ проверяет всё до отправки»;
- **У2** — «делаю, ПМ проверяет выборочно и по эскалациям»;
- **У3** — «делаю и информирую ПМ отчётом».

Порядок передачи соответствует приоритетам пользователя: **контроль сроков → общение с поставщиками →
проверка КД**. Затем идёт крупнейший по часам блок — обращения продаж.

## 0. Подготовка до выхода (ответственный — ПМ, ≈ 8–10 ч)

| Что | Зачем |
|---|---|
| Доступы: 1С, BI, Битрикс24, почта направления, кабинеты МП (просмотр) | Работа с первого дня |
| Шаблоны писем поставщикам (EN), шаблон МОМ | Стандартизация переписки и протоколов |
| Черновик чек-листа первичной проверки КД (1 страница) | Основа функции F07 |
| Перечень регулярных совещаний с пометками «лично / АПМ / протокол» | Ревизия совещаний |
| Объявление продажам о новом порядке обращений (с даты, когда начнётся этап 2) | Переключение потока обращений |
| Соглашение о неразглашении коммерческой тайны | Обязательно до доступа к данным |

## 1. Дни 1–30. Погружение и контроль сроков

| Функция | Уровень | Что делает помощник |
|---|---|---|
| Ассортимент, применяемость, основы КД | Обучение | Изучает каталог, 2–3 проекта КД с ПМ, посещает производство и ОТК |
| F01 МОМ и контроль поручений | У1 → У2 | Протоколирует все совещания ПМ, ставит задачи в Битрикс24, с 3-й недели отправляет еженедельный отчёт о просрочках |
| F06 Поставщики | У1 | Читает переписку в копии, готовит черновики запросов, ведёт реестр запросов и сводку КП |
| F02 Обращения продаж | Наблюдение | Слушает и регистрирует обращения в журнале, к концу месяца отвечает на простые с проверкой ПМ |
| F10 Рекламации | У2 | Регистрирует рекламации, собирает пакет данных |
| F13 Битрикс24 | У2 | Ключевой пользователь: тестирует, заводит справочники |

**Ожидаемое высвобождение времени ПМ:** ≈ 30–40 ч/мес.

**Контрольная точка, день 30 (встреча 1 ч):**
- МОМ рассылается в срок;
- реестр поручений ведётся;
- помощник знает основные группы ассортимента;
- подтверждаются KPI на 30 дней.

## 2. Дни 31–60. Поставщики, КД, первая линия продаж

| Функция | Уровень | Что делает помощник |
|---|---|---|
| F01 Контроль поручений | У3 | Ведёт полностью, эскалирует повторные срывы |
| F06 Поставщики | У2 | Самостоятельно запрашивает цены, сроки, уточнения по утверждённым ТЗ. Условия и обязательства — только через ПМ |
| F07 Первичная проверка КД | У1 | Проверяет все новые комплекты по чек-листу, ПМ сверяет со своими замечаниями. Помощник ведёт реестр КД и сроки КО |
| F02 Обращения продаж | У2 | Принимает поток первым, отвечает по таблице применяемости и FAQ, нестандартное эскалирует |
| F09 Расчёты OEM | У1 | Считает по шаблону, ПМ проверяет 100 % расчётов |
| F05 Сводка МП | У2 | Еженедельная сводка из BI |
| Проект: FAQ и график новинок | — | FAQ к дню 60, график новинок в Битрикс24 к дню 45 |
| Проект: база применяемости | — | Старт: структура согласуется с ПМ, наполнение ходового ассортимента |

**Ожидаемое высвобождение времени ПМ:** ≈ 70–80 ч/мес.

**Контрольная точка, день 60:**
- без эскалации закрывается ≥ 45 % обращений;
- первичная проверка КД выявляет ≥ 70 % формальных замечаний;
- ошибок в ответах по применяемости нет;
- принимается решение о переводе проверки КД на У2.

## 3. Дни 61–90. Полная передача операционного контура

| Функция | Уровень | Что делает помощник |
|---|---|---|
| F02 Обращения продаж | У2 → У3 | Работает как первая линия, ≥ 60 % обращений без эскалации |
| F06 Поставщики | У2 → У3 | Ведёт операционную переписку и статусы по всем 8 поставщикам |
| F07 Первичная проверка КД | У2 | ПМ проверяет выборочно, техническое согласование остаётся за ПМ |
| F09 Расчёты OEM | У2 | ПМ проверяет перед отправкой клиенту (контроль сохраняется всегда) |
| F08, F03, F11 Аналитика | У2 | Мониторинг цен, данные по рынку для новой ТГ, конкурентный анализ при размещении |
| F04 Спецификация новой ТГ | У1 | Оформляет по вводным ПМ |
| Проект: база применяемости | — | Опубликована для продаж (≥ 80 % ходового ассортимента) к дню 75 |
| F14 Обучение продаж | У2 | Готовит материалы и проводит короткий инструктаж по работе с базой |

**Ожидаемое высвобождение времени ПМ:** ≈ 110–120 ч/мес. ПМ получает ≥ 45 ч/мес на новую ТГ.

**Итоговая контрольная точка, день 90 (итоги испытательного срока):**
1. Сравнить KPI с целями на 90 дней (документ 5).
2. Сравнить фактические часы ПМ с базой 227 ч/мес.
3. Принять решение о прохождении испытательного срока.
4. Пересмотреть матрицу функционала: что передать дополнительно, что вернуть.
5. Провести ревизию совещаний по итогам 3 месяцев.

## 4. Риски передачи и меры

| Риск | Мера |
|---|---|
| Продажи продолжают звонить ПМ напрямую | Объявление от РГ, переадресация на помощника, отчёт о прямых обращениях |
| Ошибка в применяемости → рекламация | Ответы только по базе; всё вне базы эскалируется; ежемесячная проверка базы ПМ |
| Помощник принимает обязательства перед поставщиком | Раздел 5 ДИ, шаблоны писем, копия переписки ПМ до дня 60 |
| ПМ не отпускает функции («быстрее сделаю сам») | Фиксированные уровни самостоятельности и контрольные точки |
| Перегрузка помощника в месяцы 2–3 из-за базы применяемости | Последовательное подключение функций, база — только ходовой ассортимент |
| Снижение качества проверки КД | Технический акцепт остаётся за ПМ, помощник выполняет только формальную проверку |
