# Документ 1. Матрица функционала руководителя

**Должность:** продакт-менеджер. **Основание:** интервью с пользователем.
**Обозначения:** «Ф» — факт со слов пользователя; «О» — оценка аналитика (допущение).

Категории делегирования: **А** — оставить за руководителем; **Б** — полностью передать помощнику;
**В** — частично передать; **Г** — автоматизировать; **Д** — передать профильному подразделению.

## 4. Выявленные неэффективности

1. **Продажи используют ПМ как справочную службу.** Нет общедоступной базы применяемости и графика
   новинок — информация хранится у ПМ.
2. **Дублирование анализа МП** с менеджером МП; данные собираются вручную при наличии BI.
3. **Нет единого реестра поручений** — контроль сроков подразделений ведётся через совещания и почту.
   Решается внедрением Битрикс24 и передачей контроля помощнику.
4. **Стратегическая функция вытесняется операционной:** работа по новой ТГ не выполняется в плановом
   объёме.
