# Личный Telegram-бот «Доски проектов» (без ИИ)

Код: `server/telegram/personalBot.js`, вход — `server/telegram/personalChannel.js`. Работает на Railway
через существующий webhook, круглосуточно, без Anthropic API и без агента Claude Code.

## Команды и меню

| Команда / кнопка | Что делает |
|---|---|
| `/start`, `/help`, «❓ Помощь» | приветствие и справка, главное меню |
| `/tasks`, «📋 Задачи» | активные задачи (просроченные и высокий приоритет — выше), код `/t_xxxxxxxx` у каждой |
| `/t_xxxxxxxx` или номер из списка | карточка задачи: «✅ Выполнено» / «↩️ Вернуть в работу», «🔁 Статус», «✏️ Изменить» |
| `/new`, `/new <название>`, «➕ Новая задача» | пошагово: название → описание → срок → приоритет → ответственный → подтверждение |
| `/projects`, «🛠 Проекты» | инженерные проекты по этапам, поиск (`/projects haval jolion`), карточка `/p_xxxxxxxx` — только просмотр |
| `/cancel`, «✖️ Отмена», `/menu` | отмена ввода, главное меню |
| любой другой текст | «Создать задачу «…»?» — дальше тот же пошаговый диалог; текст не угадывается |

Статусы задачи — категории доски: Распредели, Срочно, Мои задачи, Отдай другому, Отложить, плюс отметка
выполнения. Срок: «сегодня», «завтра», «послезавтра», `25.12`, `25.12.2026`, `2026-12-25`, можно с
временем `10:30` (часовой пояс `TELEGRAM_BOT_TIMEZONE`, по умолчанию Asia/Yekaterinburg).

## Данные и надёжность

- Задачи — та же коллекция `tasks`, что и вкладка «Доска»; приоритет и описание видны в карточке на доске.
- Состояние диалога — объект `telegram_dialogs` в том же `shturman.json` (не отдельное хранилище),
  забывается через 2 часа бездействия.
- Каждое изменение — с версией задачи; если задачу параллельно изменили на доске, бот не перезаписывает,
  а показывает актуальную карточку.
- Повторная доставка: webhook пропускает повтор `update_id`; задача из диалога получает id
  `tg-<chat>-<message_id>`, поэтому то же сообщение с новым `update_id` второй задачи не создаёт.
- Кнопки — обычная клавиатура Telegram (reply keyboard): нажатие приходит как сообщение, поэтому
  webhook (`allowed_updates: ["message"]`) менять не нужно.
- Доступ: только чат `TELEGRAM_OWNER_CHAT_ID` и пользователь `TELEGRAM_OWNER_USER_ID` (задайте его —
  без него допускается любой отправитель в этом личном чате). Чат КО обрабатывается отдельно и
  никогда не получает ответов.
- `TELEGRAM_PERSONAL_AI_ENABLED=true` возвращает старый необязательный режим, где нераспознанный текст
  уходит в платный ИИ. По умолчанию выключено.
